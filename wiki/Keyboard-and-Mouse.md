# Keyboard and Mouse

## Keyboard

| Key | Action |
|---|---|
| **Ctrl + Z** | Undo |
| **Ctrl + Y** | Redo |
| **Ctrl + C** | Copy the selection |
| **Ctrl + X** | Cut the selection |
| **Ctrl + V** | Paste (as a floating image) |
| **Ctrl + A** | Select the whole active layer |
| **Enter** | Place the floating pasted image (Confirm Paste) |
| **Esc** | Remove the selection |
| **Shift** (while dragging with Line) | Snap the line to Simutrans slopes |

## Mouse (on the canvas)

| Action | Result |
|---|---|
| Left click / drag | Use the current tool |
| Right-button drag | Pan the view |
| Wheel | Scroll vertically |
| Shift + wheel | Scroll horizontally |
| Ctrl + wheel | Zoom in or out toward the mouse position |

## Mouse (other areas)

| Where | Action |
|---|---|
| Layer panel thumbnail | Click to make that layer active |
| Layer panel checkbox | Show or hide the layer |
| Layer offset arrows | Click to move by 1 px; hold to keep moving |
| Prism Left/Right swatches, Color Replace swatches | Click to open a color picker |
| Color Replace Base Shade swatches | Click to choose the base player-color shade |
